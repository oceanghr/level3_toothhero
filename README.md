Level 3 — Brush It Right (simulasi sikat gigi)
C3 · Menerapkan
Aktivitas: Anak membantu karakter mempraktikkan langkah menyikat gigi melalui simulasi, misalnya memilih sikat dan pasta gigi, lalu menggerakkan sikat pada bagian-bagian gigi.
Tujuan: Anak menerapkan pengetahuan tentang cara merawat gigi dalam sebuah simulasi.
Bentuk gameplay: Simulasi interaktif, bukan sekadar menyusun urutan kartu.
